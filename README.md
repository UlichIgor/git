# Git — інструкція та інтерактивний курс

Навчальний репозиторій для практичного вивчення **Git** українською мовою: від створення локального репозиторію до роботи з гілками, злиттям і віддаленим GitHub.

## Інтерактивний курс

👉 **[Відкрити курс Git](./course/)**

У курсі є:
- 7 послідовних навчальних модулів із прикладами команд;
- практичні підказки для роботи в тестовому репозиторії;
- 7 мінітестів із поясненнями відповідей;
- фінальний іспит із 10 запитань (прохідний бал — 8/10);
- автоматичне збереження прогресу в браузері.

## Швидкий довідник команд

| Команда | Призначення |
|---|---|
| `git init` | Ініціалізує новий локальний репозиторій |
| `git clone URL` | Клонує віддалений репозиторій |
| `git status` | Показує стан робочої директорії |
| `git add FILE` | Додає зміни до staging area |
| `git commit -m "message"` | Створює коміт із підготовлених змін |
| `git log --oneline` | Показує коротку історію комітів |
| `git branch` | Переглядає локальні гілки |
| `git switch -c NAME` | Створює гілку та перемикається на неї |
| `git merge NAME` | Зливає вказану гілку в поточну |
| `git fetch` | Завантажує зміни з remote без автоматичного злиття |
| `git pull` | Отримує та інтегрує віддалені зміни |
| `git push` | Надсилає локальні коміти у віддалений репозиторій |
| `git revert COMMIT` | Скасовує зміни коміту новим комітом |
| `git stash` | Тимчасово відкладає незакомічені зміни |

## Базовий робочий процес

```bash
git status
git add README.md
git diff --staged
git commit -m "Update documentation"
git push
```

## Публікація курсу через GitHub Pages

У репозиторії налаштовано GitHub Actions workflow: `.github/workflows/deploy-course.yml`. Він публікує вміст каталогу `course/` після змін у ньому або за ручним запуском.

1. Відкрий **Settings → Pages**.
2. У розділі **Build and deployment** встанови **Source: GitHub Actions**.
3. Перевір виконання workflow у вкладці **Actions**.

## Важливо

Практикуйся в окремому тестовому репозиторії. Команди на кшталт `git reset --hard` можуть безповоротно видалити незбережені локальні зміни.
